# Security

devbrief runs on your machine and reads your repos, your `gh` login and the
MCP connectors you already have in Claude Code. It has no server and sends
nothing anywhere else.

If you find a security problem (for example, a way for a repo's files to make
devbrief run commands, or a leak of tokens into a brief or snapshot), please
report it privately through
[GitHub's private vulnerability reporting](https://github.com/WaleedOH/devbrief/security/advisories/new)
instead of opening a public issue. You'll get a reply within a week.
